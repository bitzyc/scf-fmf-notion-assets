# Binary-phase 2D MMI final-review figures

Public image assets for embedding in the Notion page:
https://www.notion.so/3722f066c71681dca075f264775cc6e9

The relative field-plane figures are for shape comparison. SMF input panels normalize channel power to the strongest active SMF. The absolute-power figures use the same display convention: max SMF input power = 1, so equal-power N=10 has total independent input power 10.
